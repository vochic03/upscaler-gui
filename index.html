Advanced — every setting

The GPU is released when the job ends, and the card is stopped rather than thrown away — so the weights stay on its disk and the next run of the same engine does not download them again. The diffusion weights are eleven gigabytes and Hugging Face serves them at 5–9 MB/s, which is twenty minutes of card time on every run. A stopped card still costs its volume disk ($0.20/GB/month), so throw them away when you are done.

API Anything turns this program's API into operations an agent can call — so Claude Code, Cursor, Gemini CLI or VS Code can upscale a film without you clicking. The cloud routes still need your approval of the price: an agent can ask what it costs, and only you can say yes.

Only the prompt-guided engines use this. It is not a filter description: it is the texture and the mood the model aims at when it rebuilds the missing detail.

The AI pass goes to the rented GPU. The denoise, the blend, the softening, the grain, the grade and the encode stay on this Mac, so your machine only does the cheap CPU work.

STAR runs on a free NVIDIA GPU in the cloud. Your clip is uploaded to huggingface.co — only do this with footage you are allowed to upload.
